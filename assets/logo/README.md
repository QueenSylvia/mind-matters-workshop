# Logo

Put the Mind Matters logo files in this folder.

**Recommended:**
- `mind-matters-logo.svg` — primary, for the header and footer
- `mind-matters-logo-white.svg` — a light version for the dark footer, if needed
- `mind-matters-logo@2x.png` — raster fallback, roughly 380 × 104 px

**Reserved space:** the header slot is 190 × 52 px (shrinking to 44 px tall once the page
is scrolled). A logo with a roughly 3.5:1 width-to-height ratio will fit without changes.

See "Adding the real logo" in the project `README.md` for the two lines to edit in
`js/site.js`.
