# Prototype images

Put workshop photographs, slide screenshots, worksheet scans and activity materials here.

Suggested naming:
- `slide-01-emotions.png`
- `worksheet-emotion-identification.png`
- `activity-cards.jpg`
- `session-photo-01.jpg`

**Guidance**
- Export images around 1600 px wide — large enough to stay sharp, small enough to load fast.
- Every image needs descriptive `alt` text when added to `prototype.html`.
- Check that you have permission before publishing any photograph that includes students.

See "Adding prototype images" in the project `README.md` for the markup to use.
